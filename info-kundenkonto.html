Info Kundenkonto

Hier erfahren Sie alles rund um Ihr Kundenkonto bei uns. Wenn Sie Schwierigkeiten beim Einloggen haben oder Ihre Kontodaten ändern möchten, können Sie in diesem Abschnitt alle relevanten Informationen finden. Unser Kundenservice hilft Ihnen auch gerne weiter, falls Sie auf Probleme stoßen.

Passwort vergessen: Sollten Sie Ihr Passwort vergessen haben, können Sie es ganz einfach zurücksetzen, indem Sie auf den "Passwort vergessen"-Link auf der Anmeldeseite klicken. Ein neues Passwort wird Ihnen dann per E-Mail zugeschickt.

Registrierung: Für eine erfolgreiche Registrierung benötigen Sie eine gültige E-Mail-Adresse und müssen mindestens 18 Jahre alt sein. Nach der Registrierung können Sie Ihr Kundenkonto jederzeit verwalten.

E-Mail-Adresse ändern: Falls Sie keinen Zugang mehr zu Ihrer E-Mail-Adresse haben, kontaktieren Sie uns bitte über die Kundenhotline, damit wir Ihnen weiterhelfen können.

Konto löschen: Wenn Sie Ihr Konto löschen möchten, können Sie dies ganz einfach im Bereich "Konto entfernen" in Ihren Kontoeinstellungen tun.
